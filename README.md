# Polymorphic Dynamic Array 

##  Описание

Реализация абстрактного типа данных «полиморфная коллекция» на основе динамического массива для лабораторной работы №1 по курсу информатики.  

Проект демонстрирует хранение и обработку объектов различных типов (`Student`, `Teacher`) через единый интерфейс `void*`, обеспечивая строгий контроль типов, безопасное управление памятью и покрытие модульными тестами.

  

##  Ключевые особенности

- 🔹 **Полиморфизм на `void*`**: Массив хранит указатели, тип и поведение элементов определяются через структуру `ElementInfo`.

- 🔹 **Владение памятью**: При добавлении элемент автоматически клонируется (`clone`), при удалении массива или очистке — корректно освобождается (`destroy`). Исключены утечки и висячие указатели.

- 🔹 **Ленивая инициализация**: Фабрики `element_info_*()` используют мемоизацию, возвращая единственный экземпляр метаданных на тип (паттерн «объект-как-глобальная-константа»).

- 🔹 **Операции**: Реализованы `map` (трансформация), `where` (фильтрация), `concat` (конкатенация).

- 🔹 **Надёжность**: Проверка всех вызовов `malloc`/`realloc`, возврат кодов ошибок, безопасный ввод в CLI (`fgets` + `strtol`/`strtod`).

- 🔹 **Тестирование**: Модульные тесты на **Google Test** покрывают ядро, полиморфизм, операции и граничные случаи.

- 🔹 **CLI**: Интерактивная оболочка для ручной проверки всех операций.

##  Сборка и запуск

Проект использует CMake 

  

# 1. Переход в директорию проекта

cd variant17

  

# 2. Создание папки сборки и конфигурация

mkdir build && cd build

cmake -S .. -B .

  

# 3. Сборка в режиме Release

cmake --build . --config Release

  

##  Запуск программы

  

.\Release\v17.exe
