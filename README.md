# Polymorphic Dynamic Array 

Полиморфный динамический массив на C с единым буфером, способный хранить студентов и преподавателей в одном контейнере без срезки.

## Особенности реализации

* **Единый буфер** (`void* data`) — все элементы лежат в непрерывном куске памяти.
* **Полиморфизм через `ElementInfo`** — метаинформация типа (размер, clone, destroy, print) позволяет единообразно работать с разными типами данных.
* **Общая структура `PersonRecord`** — студент и преподаватель имеют одинаковый размер благодаря `union` и дискриминатору `RecordType`. Это решает проблему срезки и позволяет смешивать типы в одном массиве.
* **Безопасное владение памятью** — при вставке объект клонируется в буфер, для временных клонов вызывается `destroy`. Выход за границы и двойное освобождение исключены.
* **Совместимость** — `array_concat` проверяет равенство размеров элементов и совместимость `ElementInfo`.

## Поддерживаемые операции

| Операция | Описание |
|----------|----------|
| `push` | Добавление копии объекта в конец массива |
| `get` | Доступ к элементу по индексу (указатель внутрь буфера) |
| `remove_at` | Удаление элемента со сдвигом хвоста |
| `clear` | Очистка массива (сброс размера) |
| `map` | Применение функции-трансформации ко всем элементам, создание нового массива |
| `where` | Фильтрация по предикату, создание нового массива |
| `concat` | Объединение двух массивов одинакового типа в новый массив |

## Типы данных

### `PersonRecord` (общий для студента и преподавателя)

```c
typedef struct {
    char full_name[100];
    int age;
    int id;
    RecordType type;   // RECORD_STUDENT или RECORD_TEACHER
    union {
        struct { double gpa; } student;
        struct { int experience_years; char subject[50]; } teacher;
    } data;
} PersonRecord;
```

##  Сборка и запуск

Проект использует CMake 

  

# 1. Переход в директорию проекта

cd variant17

  

# 2. Создание папки сборки и конфигурация

mkdir build && cd build

cmake -S .. -B .

  

# 3. Сборка в режиме Release

cmake --build . --config Release

  

##  Запуск программы

  

.\Release\v17.exe

  

##  Запуск тестов

  

.\Release\run_tests.exe
